# Security

This public repository contains only the frontend and approved public artifacts. Never add private GitHub tokens, App keys, source code from private repositories, raw resume configuration, or private automation reports.

The browser fetches static JSON, validates its shape and escapes text through React. It does not access private GitHub APIs. Icons are generated PNGs. External project URLs are explicit approved metadata. A separate private automation system is responsible for schema validation, URL checks, asset safety, resume generation and source isolation.

All content here, including unmerged PR branches, is public. Review disclosures before publishing. The owner merges changes; automation must not approve or merge its own PRs. Report security concerns privately to the owner without posting private repository details.
